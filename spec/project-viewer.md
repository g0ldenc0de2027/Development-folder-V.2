# Локальный просмотрщик проектов

Статус: READY для PTR-001–PTR-005 по поручению владельца реализовать согласованный план.

- PTR-001. Стабильные ID проектов и явно подключаемые рабочие папки.
- PTR-002. Поиск по ID и названию, фильтры состояния, блокировки и ожидания решения.
- PTR-003. Исходный Markdown как текст, группировка совпадающих копий и показ расхождений.
- PTR-004. Ссылки на PR и CI и проверка явно указанных ревизий отдельно от статуса.
- PTR-005. Обновление по запросу, диагностика и последнее прочитанное состояние при сбое.

Среда: Windows и PowerShell 7.6 LTS. Панель доступна на loopback по случайному адресу сеанса. Запись в источники и автоматические действия GitHub исключены. Приёмка: изоляция проектов, Unicode, недоступный источник, расхождения, безопасное отображение и сравнение с ручным поиском.
