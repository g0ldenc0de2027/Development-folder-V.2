# Пилот единого трекера проектов

Статус — DRAFT, подготовлен к READY-review. База — PTR-001–PTR-005. Первый срез подключает одну явно выбранную очередь в режиме чтения.

## Данные и интерфейс

Реестр просмотрщика вне Git хранит ссылки на выбранную очередь и связи существующих заданий. Ключ задачи — projectId + taskId. Ключ задания — queueId + assignmentId. Одна задача может иметь несколько заданий. В пилоте связь задаётся явно в реестре. Позднее формат выдачи может передавать её непосредственно в карточке. Неподтверждённые связи не выводятся как установленные.

В карточке задачи отображаются исполнитель по данным задания, состояние обмена, отчёт и следующее действие. Состояние задачи берётся из её карточки. Состояние PR и CI отображается отдельно с доступными ссылками и ревизиями. Сданный отчёт без принятой копии ожидает проверки. Принятый отчёт сам по себе не закрывает проектную задачу.

Читать только явно подключённый источник. Задания и отчёты отображать как текст. При недоступности источника сохранить предыдущий снимок с отметкой времени и диагностикой. Различие SHA-256 сданной и принятой копий отображать как конфликт. Перед выдачей следующего действия учитывать подтверждённые данные и состояние источника. Явное следующее действие владельца сохраняет приоритет над подсказкой панели.

## Приёмка

| Проверка | Ожидаемый результат |
|---|---|
| Реальная задача и подтверждённая связь | Из карточки открывается соответствующий отчёт и виден следующий шаг. |
| Два задания на задачу | Обе записи видны со своими статусами и отчётами. |
| Задание без связи | Видно отдельно, без догадки по названию. |
| Одинаковые ID задач в двух проектах | Данные не смешиваются. |
| Недоступная очередь | Остальные источники обновляются. Данные очереди помечены устаревшими. |
| Разные хеши двух копий | Диагностика конфликта вместо подтверждённой приёмки. |
| Принятый отчёт и открытая задача | Статусы показаны независимо. |

Автоматическое назначение, приёмка из интерфейса, сетевой сбор данных и расчёт прогресса требуют отдельных срезов.
