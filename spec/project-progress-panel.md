# Ход разработки — первый выпуск

Статус — READY для PTR-VIS-001–004 и PTR-VIS-008. Состав утверждён владельцем 2026-11-26. Расширяет локальный просмотрщик PTR-001–005 и пилот T-101.

| ID | Требование | Приёмка |
|---|---|---|
| PTR-VIS-001 | Показывать подтверждённый старт, этапы, число задач по статусам и блокеры. Показатели открывают отфильтрованный список. | У двух проектов совпадает ID задачи, но цифры считаются раздельно. Без явной даты показывается «Старт не указан». Блокировка не меняет основной статус. |
| PTR-VIS-002 | Показывать шкалу этапов с плановыми и фактическими датами, контрольными точками и отметкой «Сегодня» в часовом поясе проекта. | Из этапа открываются его задачи. Этап без даты виден в списке. План и факт различимы по текстовым подписям. |
| PTR-VIS-003 | Дать доску и список с общим поиском, фильтрами и открытой карточкой. Показывать статус, ответственного, блокер и следующее действие. | При переключении сохраняются идентификаторы задач, фильтры и открытая карточка. Неизвестный статус виден явно. Поиск по кириллице и открытие карточки доступны с клавиатуры. Из поиска через «К результатам» можно перейти к первой задаче текущего вида или к сообщению о пустой выдаче. |
| PTR-VIS-004 | Показывать свежесть и доступность каждого источника и доступное покрытие датированными событиями. | При отключении источника сохраняется последний прочитанный снимок текущего сеанса с отметкой устаревания. Первый сбой без снимка показывает недоступность. После восстановления выбранный проект, фильтры и открытая карточка сохраняются. |
| PTR-VIS-008 | Дать очередь задач, ожидающих решения владельца, по подключённым проектам. | Для каждой задачи видны проект, действие и доступное доказательство. Отчёт агента отделён от приёмки задачи. При неизвестной дате ожидания выводится «Нет даты». |

Источники — явные записи локального реестра, карточки рабочих деревьев и необязательная очередь T-101. Метаданные дат и этапов задаются явно. Перенос пути не меняет ID. Панель доступна на loopback, работает в режиме чтения и сохраняет границы доступа действующего просмотрщика. Недоступность источника не означает удаление задач.

Отчёт за период, постоянная история, выгрузка, зависимости и прогноз относятся к следующим этапам. После первого выпуска сравнить размер ответа и время обновления с исходным замером на том же наборе. Браузерная приёмка охватывает клавиатуру, узкое окно, сбой и восстановление источника с открытой карточкой.
