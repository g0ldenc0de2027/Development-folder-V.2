# Интерфейс, языки и справка

Редакция 0.2.0 · 2026-11-15 · Codex, gpt-6.1-sol.
Область и приоритет — [RULES](../RULES.md). Это нормативный текст, не отчёт о реализации.

## Правило 7. Интерфейс и доступность

Для пользовательского UI обязательны согласованные светлая/тёмная темы и девять
цветовых схем через theme tokens. Не подставлять постоянные цвета в компоненты.
Предусмотреть keyboard navigation, focus, контраст, screen readers и состояния
loading/empty/error/success. Проверять реальные пользовательские сценарии.
Для headless API/CLI применяются соответствующие требования читаемости и доступности.

Схемы: синий, индиго, фиолетовый, розовый, красный, оранжевый, янтарный, зелёный,
бирюзовый в каждой теме — 18 сочетаний. По умолчанию системная тема и синяя схема;
выбор сохраняется. Палитра меняется по согласованию без потери контраста.
OKLCH или иная модель цвета сама не гарантирует доступность.
Измерять контраст после изменения цветов, состояния controls, RTL, zoom и reduced motion.
Скриншот и automated a11y дополняют клавиатурные/screen-reader сценарии.

## Правило 15. Локализация

Пользовательские UI-строки хранятся в resources, архитектура локализации закладывается с первого дня.
Утверждённый владельцем список языков сохраняется:

| Язык | Код |
|---|---|
| Русский | ru |
| Английский | en |
| Китайский, упрощённый | zh-Hans |
| Хинди | hi |
| Испанский | es |
| Арабский | ar |
| Французский | fr |
| Бенгальский | bn |
| Португальский, Бразилия | pt-BR |
| Немецкий | de |

Арабский — RTL. Plural, даты, числа, шрифты и подстановки проверяются по locale;
количество грамматических форм не обязано совпадать у разных языков.
URL/код/числа/недирекционные иконки не зеркалятся механически.
Смысловые ключи интерфейса одинаковы, fallback не маскирует отсутствующий перевод перед релизом.
Protocol fields/error codes/flags стабильны; объяснения локализуются отдельно.
Корпус знаний и программные идентификаторы принудительно переводить не нужно.


## Правило 16. Справка

Каждая новая пользовательская возможность описана в той же задаче.
Справка на русском и английском; команды и примеры проверены на текущей версии.
Для CLI/API — применимые --help/reference/integration examples.
Скриншоты/сценарии соответствуют реализации; приватные инструкции не публикуются всем.

Справка включает установку, первый запуск, функции, настройки, ошибки/восстановление,
конфиденциальность и поддержку. Приёмка сверяет реальные сценарии ru/en и их смысловые
разделы; наличие index.md само по себе не подтверждает полноту.
Профильная UI-локализация проверяет ключи/подстановки/plural и layout на всех десяти языках.
До появления UI эти проверки отмечаются по применимости, а не объявляются прошедшими.
