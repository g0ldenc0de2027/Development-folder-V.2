# Урок: отделять задачи до начала изменения

Наблюдение: совместная правка одного дерева затрудняет происхождение diff и review.
Причина: несколько исполнителей меняют пересекающиеся файлы без явного владельца.

Закрепление: отдельные task branch/worktree, baseline SHA, write-set и scope check
по полному diff. Общие контракты интегрируются раньше зависимых задач.
Один Git status не доказывает отсутствие посторонних committed изменений.

Приёмка: итоговый PR содержит только файлы задачи, а review связано с exact head.
Это урок-предложение; факт успешного enforcement проверяется на текущей автоматике.
