# Урок: учитывать UTF-8 byte limit для GIT_DIR в Git for Windows

**Статус:** причина воспроизведена, исправление покрыто локальным gate, 2026-11-19

## Симптом

Полный quality gate иногда завершал task-scope regressions с fatal: GIT_DIR too big; отдельный запуск набора проходил. Отказ зависел от полного внешнего временного пути.

## Причина

В Git upstream setup_explicit_git_dir проверяет длину GIT_DIR как байты (strlen) и прекращает работу, когда она больше PATH_MAX - 40 ([закреплённый исходник Git](https://github.com/git/git/blob/7814e8a05a59c0cf5fb186661d1551c75d1299b5/setup.c#L812)). В Windows пути с кириллицей занимали 196 символов .NET, но 221 байт UTF-8; Git for Windows отвергал такой fixture path. Проверка только по числу символов не выявляла превышение.

## Закрепление

Quality gate использует короткий уникальный каталог gate-<GUID> и до создания временных файлов рассчитывает UTF-8 размер максимально длинного GIT_DIR для linked-worktree fixtures. При превышении текущего бюджета 200 байт он останавливается с понятной рекомендацией выбрать более короткий TemporaryRoot. Task-scope suite имеет такой же ранний guard, чтобы самостоятельный запуск тоже не заканчивался неясным Git fatal.

## Регрессия и evidence

Регрессия использует TempRoot с 80 кириллическими символами: по символам путь выглядит допустимым, но UTF-8 byte count превышает бюджет. И task-scope suite, и quality gate должны отказать до записи. Проверка принадлежности TempRoot репозиторию выполняется раньше byte budget: это сохраняет точную причину отказа для пути внутри bare `.git`. Полный локальный quality gate прошёл на внешнем TempRoot с расчётным fixture GIT_DIR 194 байта при бюджете 200: KB 44/44, task-scope 8/8, privacy/hygiene, actionlint и Gitleaks PASS. Причина предыдущего отказа была воспроизведена при 221 байте. Результат относится к текущей незакоммиченной кандидатной рабочей копии; hosted CI и независимое review ещё не подтверждены.

## Граница

Git upstream использует PATH_MAX - 40; наблюдаемый порог текущей сборки — 220 байт. Guard намеренно использует запас: 200 UTF-8 bytes. При обновлении Git for Windows проверку нужно повторить. Это локальный тестовый путь linked worktree, а не ограничение всех путей приложения или всех Git-платформ.
