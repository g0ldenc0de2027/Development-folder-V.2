# Уроки проекта

| Запись | Проблема | Закрепление |
|---|---|---|
| [Изоляция задач](records/task-isolation.md) | Смешанный diff | Worktree + write-set + полный PR scope |
| [Глобальный audit worktree](records/task-worktree-recovery.md) | Dirty соседние worktree терялись из обзора; audit зависел от shell cwd; untracked/ignored .vs и путь к read-only источнику могли быть пропущены; зарегистрированный .worktrees/main ошибочно блокировался проверкой имени; агентские temp-артефакты могли остаться после тестов; чрезмерно длинный внешний temp-путь ломал вложенный Git fixture | Общий fail-closed audit с проверкой точного пути и Git-регистрации; разрешать только зарегистрированный main, остальные orphan/неожиданные каталоги блокировать и сохранять; reparse guards, изоляция Git-контекста, recovery через verifier, точечная очистка только своего per-run temp и проверка длины максимального fixture-пути |
| [Окончания строк при правке на Windows](records/task-worktree-recovery.md) | PowerShell вставил CRLF в LF-only файл, и regression остановил gate до публикации | Сохранять repository-defined EOL; сверять `git ls-files --eol`, отклонять `w/mixed`, запускать diff check и gate |
| [Git в Windows sandbox Codex](records/task-worktree-recovery.md) | `rev-parse` успешен, а `status`/`diff` ложно сообщают об отсутствии worktree | Повторить read-only проверку в разрешённом execution context; не чинить Git metadata по одной sandbox-ошибке (`#в-эталон`) |
| [Git identity в linked worktrees](records/git-attribution-worktrees.md) | Общая placeholder identity, ранний расчёт commit identity, допустимые Git temporary indexes, bare-admin discovery при worktree-scoped core.bare=false и публикация recovery-ref под другим именем | Worktree-scoped identity; repair завершается отказом с безопасным повтором; pre-push проверяет outgoing metadata и оба имени защищённой T-013 ветки; bare admin определяется также по точному commonDir, а commit -a/pathspec проверяются настоящим hook E2E |

Уроки записываются при содержательном выводе. Текст конкретного урока хранится в одном месте.
Статус и SHA-256 — в catalog.json; обзор не повышает доверие к записи.
