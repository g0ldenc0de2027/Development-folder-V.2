# Уроки проекта

| Запись | Проблема | Закрепление |
|---|---|---|
| [Изоляция задач](records/task-isolation.md) | Смешанный diff | Worktree + write-set + полный PR scope |
| [Глобальный audit worktree](records/task-worktree-recovery.md) | Dirty соседние worktree терялись из обзора; audit зависел от shell cwd; untracked/ignored .vs и путь к read-only источнику могли быть пропущены | Общий fail-closed audit, проверка reparse ancestors, publish block T-013, изоляция Git-контекста и восстановление partial config через повторную настройку и verifier без автоотката |
| [Git в Windows sandbox Codex](records/task-worktree-recovery.md) | `rev-parse` успешен, а `status`/`diff` ложно сообщают об отсутствии worktree | Повторить read-only проверку в разрешённом execution context; не чинить Git metadata по одной sandbox-ошибке (`#в-эталон`) |
| [Git identity в linked worktrees](records/git-attribution-worktrees.md) | Общая placeholder identity и некорректный bare admin config | Worktree-scoped identity, safe bootstrap/migration и pre-push metadata check |

Уроки записываются при содержательном выводе. Текст конкретного урока хранится в одном месте.
Статус и SHA-256 — в catalog.json; обзор не повышает доверие к записи.
