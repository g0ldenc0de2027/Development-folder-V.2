# Локальная база знаний проекта

Формат 1, первый срез T-004. Начните с [карты проекта](records/project-map.md).
**Граница двух баз:** эта локальная база содержит сведения только Development Folder V2.
Общая база знаний — портфельная память всех проектов и может хранить нужные записи
по конкретным проектам наряду с общими нормами и опытом. Локальная запись остаётся
подробным источником своего проекта; полное автоматическое зеркало не выполняется.
Проектные сведения требуют origin project, scope, классификации и audience. Сейчас
общая БЗ лишь обнаруживается через doctor: compatibility, record-level ACL и объединённый
поиск не реализованы. Не помещайте закрытые проектные данные в общий корпус, полагаясь
только на локальный путь или права операционной системы.
Требование владельца: обе базы должны хранить и обрабатывать основные типы файлов.
Этот первый срез пока индексирует только Markdown-записи и JSON-каталог; импорт Office/PDF,
медиа, OCR/ASR, универсальный объектный архив и безопасная обработка архивов не реализованы.
До отдельного допуска форматного ingestion не помечайте такие файлы как обработанные.
Обязательный регламент: [RULES](../rules/RULES.md).
Команды и ограничения: [руководство БЗ](../docs/local-knowledge.md).

- records/ — атомарные Markdown-записи; постоянные IDs и метаданные — catalog.json.
- [УРОКИ.md](УРОКИ.md) — обзор уроков со ссылками, без второго текста записей.
- [decisions/README.md](decisions/README.md) — обзор ADR.
- templates/record.md — заготовка записи, не принятый факт.

Тело и catalog — одна версия знания, хранятся вместе в Git. После изменения тела
обновляется contentSha256; прежнее review нельзя перенести на изменённый текст.
Изменение hash только восстанавливает целостность — не подтверждает содержание.
Начальные записи draft: без независимого подтверждения они не называются accepted.
Проверяемый список ограничен catalog; README/шаблоны не выдаются за проверенный корпус.

Предложения других агентов сохраняются capture в ignored data/knowledge/inbox.
Список заданий и оперативное общение не хранятся здесь как принятые знания.
