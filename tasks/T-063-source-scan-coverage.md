# T-063 — Расширить и проверить обход исходников

Статус — в работе. Источник — аудит V2, A13 и A23.

## Зона файлов

- `scripts/ide-cache.ps1`
- `scripts/quality-gate.ps1`
- `tests/ide-cache-regressions.ps1`
- `tests/quality-gate-regressions.ps1`
- `tasks/T-063-source-scan-coverage.md`

## Приёмка

- Синтаксическая проверка включает скрипты, модули и манифесты PowerShell через общий обход.
- Обход не передаёт файловые reparse points потребителям. Проверенный проход по каталогам ProjFS сохраняется.
- Регрессии проверяют набор файлов по поведению, включая точные имена исключаемых каталогов, близкие имена и вложенные tracked scratch-пути.
- Секреты продолжают проверяться отдельным шагом Gitleaks. Точные доказательства фиксируются в PR.
