## Приёмка

- Gate отклоняет reparse point в пути временного корня до записи.
- Gate создаёт собственный каталог без перезаписи и удаляет его только после успешного создания и повторной проверки пути.
- Финальный PASS выводится после подтверждённой очистки. При отказе очистки вывод содержит путь оставшихся артефактов.
- Штатные проверки запускаются на Windows, публикация идёт через существующие hooks и PR.
- Самостоятельные Git-фикстуры и другие замечания A02 остаются отдельным этапом. Общая БЗ вне scope.
