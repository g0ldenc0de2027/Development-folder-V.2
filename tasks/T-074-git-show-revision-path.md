# T-074 — Отделить SHA от путей при чтении автора коммита

Статус: in_progress. Источник — независимое ревью PR #71 и воспроизведение неоднозначности git show.

## Зона файлов

- `scripts/lib/GitIdentity.psm1`
- `tests/git-identity-regressions.ps1`
- `tasks/T-074-git-show-revision-path.md`

## Приёмка

- При наличии файлов с именами диапазона ревизий и полного SHA проверка читает метаданные коммита и сохраняет контроль атрибуции.
- Без разделителя git show отказывает с ambiguous argument. После правки проходит набор Git identity, включая отклонение коммитов с неверным автором.
