## Приёмка

Обычный набор выполняет 68 проверок. Если один сценарий исчезает из прогона, набор возвращает код 1 с KB_REGRESSION_COUNT_MISMATCH, а quality gate блокирует результат. Исторические отчёты сохраняют числа своих ревизий. Контракт CLI БЗ сохраняется.
