## Приёмка

- До публикации pre-push проверяет, что эффективные списки fetch и push содержат по одному каноническому адресу origin.
- При пустом наборе исходящих обновлений проверка получает адрес, переданный Git в хук. Запрос опубликованной main нужен только при проверке диапазона коммитов.
- Канонический origin принимается. Лишний адрес, неканонический fetch или push отклоняются до отправки изменений.
