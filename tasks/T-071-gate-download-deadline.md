# T-071 — Ограничить полное время загрузки инструментов gate

Статус: in_progress
Источник: F11, воспроизведение медленной HTTP-передачи на PowerShell 7.6.10.

## Зона файлов

- `docs/development.md`
- `scripts/quality-gate.ps1`
- `tasks/T-071-gate-download-deadline.md`
- `tests/quality-gate-regressions.ps1`

## Приёмка

- На каждый инструмент выделено до 180 секунд на запросы, чтение тела и паузы между попытками. Подключение ограничено 30 секундами, отдельное ожидание данных — 60 секундами.
- Медленная непрерывная передача отменяется при исчерпании общего бюджета. Частичный ZIP удаляется.
- Сохраняются три попытки для прежних временных HTTP-статусов, отказ для прочих ошибок, проверка SHA-256 до распаковки.

Регрессия gate удерживает открытый HTTP-ответ на loopback после передачи части тела и проверяет отмену по общему дедлайну и удаление ZIP.
