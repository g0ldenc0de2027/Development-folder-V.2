# T-060 — Явно отклонить параметр поиска у команды get

Статус — в работе. Источник — аудит V2 от 2026-11-21, A22.

## Зона файлов

- `tasks/T-060-kb-get-query.md`

## Приёмка

- `get -Id <id>` сохраняет точный поиск записи и существующие ограничения.
- Явный `-Query` с `get` возвращает `KB_QUERY_NOT_SUPPORTED_FOR_GET`, exit 1 и пустой stdout до загрузки каталога.
- Параметр `-Query` продолжает действовать для `search` и `context`.
- Изменение относится к CLI внутри репозитория V2. Файлы и настройки общей БЗ в задачу не входят.

## Передача

Остальные сочетания параметров из A22 требуют отдельного решения о совместимости. Результаты Windows, CI и ревью точного head ведутся в PR.
