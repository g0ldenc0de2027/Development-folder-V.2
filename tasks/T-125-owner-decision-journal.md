Пилот ограничен синтетическими данными и проверяет хранение. Подключение панели затрагивает файлы, находящиеся в работе T-124, и выполняется отдельно после приёмки формата пилота. Общий допуск к эксплуатации журналу пока не выдан.


## Контракт чтения

Реестр связывает проект с относительным путём к журналу. Журнал несёт schemaVersion, projectId, список решений и полуоткрытые интервалы подтверждённого учёта. Каждое решение содержит eventId, projectId, itemId, scopeVersion, criteriaVersion, type, at и evidenceId. EventId уникален в проекте. Отзыв сохраняет отдельное событие. Связь результата с карточкой задачи явная.

Один запрос панели читает журнал один раз одним открытым дескриптором с FileShare.Delete. Из этого снимка строятся шкала, история периода, остаток и отображение приёмки в доказательствах. GitHub поставляет только слияния. Отсутствие покрытия отображается как неполнота источника. Чтение предыдущей корректной версии при ошибке помечается как устаревшее.

## Контракт сохранения

Процесс получает блокировку поддерживаемых авторов до чтения исходного снимка. Конкурент ждёт в пределах установленного тайм-аута либо завершает работу с диагностикой. Повтор идентичного события успешен без записи. Повтор идентификатора с другим содержимым завершается конфликтом. Одновременно проверяются события и покрытие. Проверенный временный файл в том же каталоге атомарно заменяет исходный. Перед заменой проверяется версия исходного файла. Гарантия сериализации действует для писателей, соблюдающих общий протокол. Произвольное редактирование между последней проверкой версии и заменой остаётся вне этой гарантии.

## Приёмка на синтетических данных

- Два писателя сохраняют разные события без потери записей. Повтор первой операции сохраняет хеш.
- Отказ до замены оставляет исходный хеш и не оставляет временного файла.
- Дескриптор старого читателя возвращает предыдущую версию, новый читатель видит следующую версию.
- При весах 3/2/3 последовательные приёмки дают 37,5%, 62,5% и 100%. Отзыв элемента весом 2 возвращает 75%. Исторический срез до отзыва остаётся 100%.
- При пропуске в покрытии панель показывает неполноту. Подтверждённый пустой интервал даёт ноль.
- Две локальные папки проектов независимы. Подмена журнала другим projectId отклоняется. При переносе каталога внутри машины относительная привязка разрешается заново.

Статус — контракт пилота. Реальные решения владельца и перенос на другой ПК за пределами проверки.
