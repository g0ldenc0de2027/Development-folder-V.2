# T-030 — Проверить бюджет ответа до выделения UTF-8 буфера

Статус: in_progress. Оптимизация действующего LKB-009.

## Зона файлов

- `scripts/kb.ps1`
- `tasks/T-030-kb-output-allocation.md`

## Приёмка

Для search/get проверять число UTF-8 байтов с учётом LF до создания выходного массива. Успешная выдача и отказ KB_OUTPUT_LIMIT с пустым stdout сохраняют существующий контракт. Загрузка и сериализация корпуса остаются прежними. Границы и многобайтовый вывод проверяет существующий набор KB-регрессий.
