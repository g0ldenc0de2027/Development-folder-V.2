# T-066 — Зафиксировать свидетельства ревью и результата squash

Статус — в работе. Источник — аудит V2, A04 и A05.

## Зона файлов

- `.github/pull_request_template.md`
- `docs/github-workflow.md`
- `scripts/github/merge-reviewed-pr.ps1`
- `tasks/T-066-squash-evidence.md`

## Приёмка

- Для изменений workflow, gate, закреплённых инструментов и защитных правил PR содержит свидетельство проверки точного diff и принятого head. Модель no-App сохраняется.
- После единственной попытки squash скрипт проверяет состояние PR, единственного родителя, дерево и автора опубликованного коммита.
- Неполный ответ мутации разрешается запросами на чтение. Расхождение или неизвестный результат завершаются ошибкой без повтора мутации.
- Положительные и отрицательные сценарии используются с подставным GitHub CLI. Реальное слияние для проверки не выполняется.
