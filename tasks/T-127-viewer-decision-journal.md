## Приёмка

- Для настроенного проекта один валидированный снимок журнала на цикл обновления используется шкалой, остатком, периодом и карточкой. Старые реестры сохраняют прежнее поведение.
- Путь к журналу относителен к реестру. Идентификатор проекта обязателен. Связь результата и карточки задаётся явно. Отсутствие связи с картой отображается диагностикой, без выдуманной привязки.
- При обновлении из другой вкладки старый кадр остаётся согласованным либо отклоняется целиком. Потеря источника помечает прежний снимок устаревшим. Путь и сырые данные журнала в HTTP не выдаются.
- Синтетический прогон F1 → запись без refresh → F1 → refresh → F2 → конфликт F1. Смена критериев, два результата одной задачи, отзыв, неполное покрытие, переключение проектов и legacy HTTP.
- Подтверждённые решения владельца и рабочий реестр не редактируются этим прототипом.
